# RocketLaunchCountdown

RocketLaunchCountdown is a python made software to operate countdown timers, go/nogo indicators, and concerns for a Rocket Launch livestream. 

## Latest release

[RocketLaunchCountdown 0.8.0](https://github.com/HamsterSpaceNerd3000/RocketLaunchCountdown/releases/tag/v0.8.0)

### Features added

- Full rewrite of the entire program, using a new GUI library.
- Replaced HTML files with seperate popouts that are their own exes.
- Fixed many bugs present in pre-0.8.0 (This was done mostly by the rewrite).
- Added auto hold and reset time.
- New logo!
- Much more!

## OBS instructions

Using this in OBS is much easier now.

- Simply create a window capture for each popout.

## Install instructions

Install is simple: download the installer, run it, and follow the prompts to install RocketLaunchCountdown.
